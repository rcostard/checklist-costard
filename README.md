# Checklist de Campo — Costard Engenharia

Ferramenta interna de apoio a inspeções prediais (disciplinas HVAC e Elétrica). Uso restrito à equipe Costard e parceiros autorizados. Nenhum dado de cliente ou de inspeção é armazenado neste repositório — todo o preenchimento fica no aparelho de quem usa.

## Como usar
1. Abra a página publicada (URL do GitHub Pages deste repositório) no Safari (iPhone/iPad) ou Chrome (Android).
2. No menu do navegador, use **"Adicionar à Tela de Início"** — o checklist vira um app e funciona offline após o primeiro acesso.
3. Em campo: preencha as abas (Geral, Anamnese, Elétrica, HVAC). Tudo é salvo automaticamente no aparelho.
4. Fotos e áudios em alta resolução: usar câmera e gravador nativos, com envio pela pasta de nuvem indicada pela coordenação.
5. Ao concluir: aba **Enviar → Gerar e compartilhar pacote** e encaminhar o arquivo gerado à coordenação.
